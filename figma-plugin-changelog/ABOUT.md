# About

A lightweight image compression plugin for Figma that helps designers optimize their exported images.

## Key Features (100% Free):
- Batch compression and export support
- Compatible with JPG, PNG and WebP formats
- Multiple compression levels (None/Light/Medium/Extreme)
- Various export scales (0.5x/1x/2x/3x/4x/6x/8x)
- Before/after file size comparison
- Processing time tracking
- Automatic ZIP packaging for multiple files
- Suffix toggle switch for exported file names
- Smart compression based on image size
- Multi-threaded parallel processing
- Pure JavaScript implementation with local processing
- No usage limits or premium features

Everything is free - no hidden costs, no premium features, just a focused tool for the design community.
