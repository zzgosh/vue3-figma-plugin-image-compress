# Release Notes Drafts

Create one Markdown file per Figma plugin release tag. This README only defines the file format; the operational release workflow lives in `AGENTS.md`.

Naming:

```text
figma-plugin-changelog/releases/figma-v9.md
figma-plugin-changelog/releases/figma-v10.md
```

These files are the shared source for GitHub Release notes and Figma plugin release notes. Use bilingual English and Simplified Chinese copy so the same content can be pasted into the Figma plugin release form.

`figma-plugin-changelog/VERSION_HISTORY.md` preserves historical releases up to Version 8. Version 9 and later should be tracked in GitHub Releases instead.
